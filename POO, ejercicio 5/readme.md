## Defensa de QTZ2, ejercicio No.5
## Obed Tot -26971

Simulador de consola en Java para administrar una misión del satélite Quetzal-2. Utiliza herencia, polimorfismo y el patrón MVC.

El programa incluye diez módulos iniciales: los de vuelo recolectan datos, los de tierra descargan información y los de energía generan energía.

Desde el menú se pueden listar y buscar módulos, consultar el catálogo por costo, avanzar ciclos y ver el resumen de comunicaciones.
